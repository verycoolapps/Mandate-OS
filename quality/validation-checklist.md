# Validation Checklist

**MANDATE OS Analysis Validation Criteria**

---

## QUICK VALIDATION (30-Second Review)

### Essential Checks
- [ ] **Problem Clear**: Is the problem being addressed clearly defined?
- [ ] **Evidence-Based**: Are factual claims supported by evidence or acknowledged as assumptions?
- [ ] **No Fabrication**: Is there any invented data, research, or credentials?
- [ ] **Alternatives Considered**: Are multiple options evaluated, not just one?
- [ ] **Trade-Offs Explicit**: Are costs, sacrifices, and risks stated?
- [ ] **Actionable**: Is the recommendation implementable?
- [ ] **Accountability**: Is it clear who does what?
- [ ] **Measurement**: Is success defined and measurable?

### Failure Modes
If any essential check fails, the analysis is incomplete and requires revision before delivery.

---

## STANDARD VALIDATION (Tier 1-2 Decisions)

### Problem Understanding
- [ ] Scope is bounded and clear
- [ ] Stakeholders are identified
- [ ] Constraints are acknowledged
- [ ] Timeline is specified

### Evidence Quality
- [ ] All assumptions are explicit
- [ ] Data sources are cited
- [ ] Confidence levels are stated
- [ ] Missing information is identified

### Analysis Depth
- [ ] Root cause analysis is present
- [ ] Multiple causes are considered
- [ ] Causal chain is logical
- [ ] Analysis depth matches complexity

### Alternatives
- [ ] At least 2-3 options evaluated
- [ ] Status quo (do nothing) considered
- [ ] Alternatives compared consistently
- [ ] Selection rationale is clear

### Trade-Offs
- [ ] What is gained is stated
- [ ] What is sacrificed is stated
- [ ] Opportunity costs are identified
- [ ] Hidden consequences explored

### Risks
- [ ] Material risks identified
- [ ] Risk impacts assessed
- [ ] Mitigation strategies specified
- [ ] Contingency plans defined

### Implementation
- [ ] Steps are actionable
- [ ] Resources specified
- [ ] Accountability assigned
- [ ] Dependencies clear

### Success Measurement
- [ ] KPIs defined
- [ ] Baselines established
- [ ] Success thresholds specified
- [ ] Review schedule clear

### Professional Integrity
- [ ] Within professional scope
- [ ] No unlawful recommendations
- [ ] Safety implications addressed
- [ ] Ethical considerations included

### Cross-Functional Review
- [ ] Relevant roles consulted
- [ ] Interdependencies identified
- [ ] Conflicting objectives acknowledged
- [ ] Stakeholder impacts mapped

- [ ] Organizational strategy considered
- [ ] Long-term implications assessed
- [ ] Portfolio impacts evaluated
- [ ] Competitive positioning addressed

### Financial Rigor
- [ ] All material costs quantified
- [ ] Financial modeling shown
- [ ] Cash flow implications assessed
- [ ] Accounting assumptions disclosed

- [ ] Regulatory implications assessed

- [ ] Safety implications paramount

- [ ] Security implications assessed

---

## ANTI-HALLUCINATION VALIDATION

### Fact-Checking
- [ ] Every factual claim has a source
- [ ] Sources are cited accurately
- [ ] No invented data or statistics
- [ ] No fabricated research or studies
- [ ] No false credential claims

### Evidence Classification
- [ ] Facts distinguished from interpretations
- [ ] Assumptions explicitly stated
- [ ] Hypotheses marked as tentative
- [ ] Unknowns identified
- [ ] Recommendations not presented as facts

### Confidence Calibration
- [ ] Confidence levels are justified
- [ ] High confidence requires strong evidence
- [ ] Uncertainty is not hidden
- [ ] Speculation is marked as such
- [ ] Language is appropriately qualified

### Source Integrity
- [ ] Citations are complete and accurate
- [ ] Source limitations are noted
- [ ] Currency of sources is appropriate
- [ ] Biases in sources are acknowledged
- [ ] Methodology is disclosed where relevant

---

## PROFESSIONAL BOUNDARY VALIDATION

### Domain Safety
- [ ] Legal analysis defers to counsel
- [ ] Medical analysis defers to professionals
- [ ] Financial analysis is clearly non-advisory
- [ ] Technical analysis is appropriately scoped
- [ ] Safety-critical domains have extra safeguards

### Ethical Considerations
- [ ] Ethical implications addressed
- [ ] Conflicts of interest acknowledged
- [ ] Stakeholder fairness considered
- [ ] Long-term societal impacts assessed
- [ ] No recommendation to violate law or ethics

### Regulatory Compliance
- [ ] Applicable regulations identified
- [ ] Compliance requirements specified
- [ ] Regulatory risks flagged
- [ ] Licensing requirements noted
- [ ] Regulatory pathways defined where needed

### Report Completeness
- [ ] Executive summary present

- [ ] Problem definition precise
- [ ] Analysis flows logically
- [ ] Recommendation is actionable

### Section Requirements
- [ ] All required sections present for tier
- [ ] No material omissions
- [ ] Consistent terminology
- [ ] Appropriate depth
- [ ] Clear section boundaries

- [ ] Language appropriate to audience
- [ ] Jargon explained or minimized
- [ ] Active voice for recommendations
- [ ] Specific rather than vague
- [ ] Quantified where possible

---

## VALIDATION OUTCOMES

### Pass
- All applicable checks passed
- Analysis is ready for delivery
- Confidence level appropriate to evidence

### Conditional Pass
- Minor gaps identified
- Gaps acknowledged in output
- Recommendations appropriately qualified
- Further investigation recommended

### Fail
- Material gaps present
- Essential checks failed
- Fabrication detected
- Professional boundaries violated
- Requires revision before delivery

---

## VALIDATION SIGN-OFF

### Validator Checklist
- [ ] Validation completed by appropriate tier
- [ ] All findings documented
- [ ] Rationale for conditional pass clear
- [ ] Revision requirements specified for fail
- [ ] Confidence level assigned
- [ ] Date and validator recorded

---

**Validation is not optional. Every analysis must pass validation before delivery.**
