## 🎯 WHAT IS MANDATE OS?

**MANDATE OS** is a modular professional decision-support skill. It organizes role-based perspectives, analytical frameworks, workflows, collaboration protocols, templates, and quality guidance.

Use it to structure analysis around a professional mandate, surface trade-offs and uncertainty, and connect recommendations to possible execution steps. The repository's modules describe the scope; outputs depend on the information supplied and should not be treated as validated professional advice.

- ✅ Modular knowledge frameworks
- ✅ Role-specific analytical perspectives
- ✅ Operational methodologies
- ✅ Decision-making frameworks
- ✅ Diagnostic protocols
- ✅ Accountability guidance

## 🇮🇩 APA ITU MANDATE OS?

**MANDATE OS** adalah skill modular untuk membantu menyusun analisis dan keputusan profesional. Isinya mencakup perspektif berbasis peran, kerangka analitis, alur kerja, protokol kolaborasi, templat, dan panduan kualitas.

## 📊 OUTPUT SHAPE | BENTUK OUTPUT

### 🇬🇧 ENGLISH

Illustrative structure only—not a real financial analysis. If the user supplies no pricing, demand, cost, or cash-flow data, MANDATE OS must not invent those values or claim a go/no-go result.

```text
Decision status: Not determined from the information provided
Evidence available: No validated pricing, demand, cost, or retention inputs
Options to compare: Limited pilot / full launch / defer
Trade-offs: State likely categories; quantify only from supplied data
Key unknowns: Unit economics, delivery capacity, legal terms, churn behavior
Next step: Gather decision-critical inputs and define pilot success/stop gates
Confidence: Limited; explain which missing evidence could change the decision
```

### 🇮🇩 BAHASA INDONESIA

Ini hanya struktur ilustratif, bukan analisis keuangan nyata. Jika pengguna belum memberikan data harga, permintaan, biaya, atau arus kas, MANDATE OS tidak boleh mengarang angka maupun menyimpulkan keputusan lanjut/tidak.

```text
Status keputusan: Belum dapat ditentukan dari informasi yang tersedia
Bukti tersedia: Belum ada data harga, permintaan, biaya, atau retensi tervalidasi
Opsi yang dibandingkan: Pilot terbatas / peluncuran penuh / ditunda
Trade-off: Jelaskan kategorinya; hitung hanya dengan data yang diberikan
Hal yang belum diketahui: Ekonomi unit, kapasitas, ketentuan hukum, pola churn
Langkah berikutnya: Kumpulkan input penting dan tetapkan kriteria sukses/henti pilot
Keyakinan: Terbatas; jelaskan bukti apa yang dapat mengubah keputusan
```
